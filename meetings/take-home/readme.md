# take-home

what leaves the meeting. the call is not over when it ends.

- transcripts: the full record, stored, citable
- captures: answers to capture requests with h:mm:ss citations back to the source, never a summary alone
- recaps: the after-surface, rendered artifacts handed back to people
- receipts: what was asked, what was answered, what is still owed

scope honesty: contract only until wired.
