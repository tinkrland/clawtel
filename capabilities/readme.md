# capabilities

what the agent does with what it receives. each capability is a folder with its own contract.

- **promo-codes**: hear a code, quote the words, urgency honored
- **recap**: fetch, transcribe, ingest, answer with citations
- **transcript**: the full record, stored and citable
- **questions**: asking and answering, live and async

scope honesty: contracts until wired. a capability that cannot verify a claim says so.
