# promo codes

hearing a code is a capture, not a copy. the words matter: what was offered, how long it lasts, whether supply is limited. captures carry the quote verbatim and the urgency kind (clock, deadline, or supply), never a paraphrase.

receipts fire only on real confirmation: a code confirmed redeemed is a receipt, a code heard is a pending capture.

scope honesty: contract until wired.
