# intake

where the agent receives from the world. every source here turns events into plans: a mail becomes a task, a calendar event becomes a meeting to join, a channel message becomes a question to answer.

planned sources:

- **mail**: inbox intake, invites, confirmations, receipts
- **channels**: slack and friends, where people talk and ask
- **calendars**: google, microsoft, apple, notion, cal.com, zcal. events in, meetings out

scope honesty: this folder states contracts only until a source is wired. a source without credentials stays closed.
