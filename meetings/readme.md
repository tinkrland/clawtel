# meetings

the meeting surface: everything that happens around, inside and after a call.

- **pre-joining**: registration, rsvps, waiting rooms, calendars deciding what to join
- **joining**: the join engine, delays, the moment of entry
- **interactivity**: what the agent can do mid-call (reactions, hands, screenshare, speaking)
- **take-home**: what leaves the call (transcripts, captures, action items)
- **platforms**: where it joins (zoom, meet, twitch, ...), one folder per platform, each with its own readme covering features and backend honestly

scope honesty: folder structure now, ports land here module by module. a platform readme that says a feature is designed means designed, never faked-live.
